Place your background video file in this folder and name it "hero-video.mp4".

The hero section will automatically use /hero-video.mp4 as the background video.
If the file is not present, a stock chocolate brownie video will be used instead.

Supported formats: .mp4, .webm
Recommended resolution: 1920x1080 or higher
Recommended duration: 10-30 seconds (it loops automatically)
